# Marca · Cadê!?

Nome escolhido pelo responsável: **Cadê!?**. A assinatura é
**Achados, perdidos e reencontros.** O nome remete à pergunta de quem perdeu um
objeto, com uma linguagem próxima e fácil de reconhecer.

## Aplicação na interface

- `frontend/src/componentes/Marca.jsx` reúne nome e símbolo de interrogação em um
  bloco dourado. Não depende de arquivo ou fonte externa.
- `docs/marca/logo.svg` fica preservado como material anterior do projeto.

## Paleta

- Azul profundo: `#172c40`.
- Dourado: `#efba4b`.
- Fundo de papel: `#f7f6f2`.
- Cartões brancos; cores de situações descritas em `docs/styleguide/README.md`.
