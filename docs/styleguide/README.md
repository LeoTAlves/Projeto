# Styleguide

## Paleta
- Azul escuro: #0f172a
- Dourado: #f59e0b
- Branco: #f8fafc
- Cinza: #cbd5e1

## Tipografia
- Títulos em sans serif com peso forte.
- Texto de apoio em tom neutro e legível.

## Direções visuais
- A interface prioriza leitura simples, botões claros e contraste forte para celular e desktop.
- O foco do visitante é o registro e o acompanhamento do aviso.
- O foco da gestão é a velocidade de leitura e a validação de ocorrências.
